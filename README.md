# NSCI Website

National Students' Council of India (NSCI) website package.

## Files
- `index.html` — complete website
- `css/style.css` — responsive design
- `js/script.js` — menu + join form behavior
- `assets/nsci-logo.png` — supplied NSCI logo
- `assets/nsci-poster.png` — supplied NSCI poster

## GitHub Pages
1. Upload the entire folder contents to your repository.
2. Keep the folder structure exactly the same.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Save and wait for GitHub Pages to publish.

## Important
The join form is front-end only in this package. For real private admin submissions, connect it to a database/form service and set the destination email/admin permissions.
